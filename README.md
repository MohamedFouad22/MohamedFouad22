## 💻 About Me

> **"Turning complex business logic into scalable, secure and production-ready backend systems."**

I'm a **Backend Engineer** focused on building robust server-side applications using **Node.js, TypeScript and NestJS**.

My main interests are backend architecture, API design, authentication, database engineering, real-time systems and application security.

I enjoy transforming requirements into clean backend architectures that are easy to maintain, test, scale and secure.

### 🚀 What I Do

* 🌐 Design and build scalable **RESTful APIs**
* 🔐 Implement secure **authentication and authorization systems**
* 🏛️ Build maintainable architectures using **Clean Architecture & Design Patterns**
* 🗄️ Design and optimize **MongoDB databases**
* ⚡ Develop **real-time applications with Socket.IO**
* ☁️ Integrate cloud services such as **AWS S3 and Cloudinary**
* 🛡️ Apply defensive programming and backend security practices
* ⚙️ Build reusable middleware, services, repositories and utilities
* 📈 Optimize database queries and backend performance

## 🏛️ Architecture & Design

I focus on separating responsibilities and keeping business logic independent from infrastructure.

```text
Request
   │
   ▼
Controller
   │
   ▼
Validation
   │
   ▼
Service / Use Case
   │
   ▼
Repository
   │
   ▼
Database
```

### Patterns & Principles

* Clean Architecture
* MVC
* Repository Pattern
* Dependency Injection
* Modular Architecture
* Separation of Concerns
* Single Responsibility Principle
* DRY
* Reusable Services & Utilities
* Centralized Error Handling
